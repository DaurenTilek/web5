# Assignment 5 — JavaScript Basics

Student: Dauren Tilek
Group: SE-2525

## Description

A website demonstrating JavaScript basics, DOM manipulation
and event handling.

## Pages

- index.html — console output, alert, variables and operators.
- dom.html — changing text and styles, adding and removing elements.
- events.html — mouse events, keyboard events and calculator.
- todo.html — adding, completing and deleting tasks.

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

Download the project and open index.html in a browser.
Use the navigation bar to switch between pages.
Open the browser console with F12 to see Tasks 0 and 1.

Tasks in the To-Do app are stored in an array.
They disappear when the page reloads.
